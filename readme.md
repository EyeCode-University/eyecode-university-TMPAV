# Задание: Тестирование ToDo приложения

> **Task ID:** `task-40`
> "-Neo Mode: FREE"

## Суть задания

Создай простое ToDo приложение на React и покрой его unit и integration тестами с помощью Jest и React Testing Library. Приложение должно уметь добавлять, удалять и отмечать задачи как выполненные.

(-Neo Mode: FREE: Для создания приложения можете использовать AI Agent)

## 📋 Пошаговый план

### Структура компонентов
- `TodoApp.jsx` — главный компонент
- `TodoForm.jsx` — форма добавления задачи
- `TodoList.jsx` — список задач
- `TodoItem.jsx` — отдельная задача

### Функционал
- Добавление новой задачи
- Удаление задачи
- Отметка задачи как выполненной
- Счётчик активных задач

### Тесты
Создай файл `TodoApp.test.js` для тестирования всего приложения.

## ✅ Чеклист перед сдачей

- [ ] Приложение работает: можно добавлять, удалять и отмечать задачи
- [ ] Написано минимум 5 unit тестов для отдельных компонентов
- [ ] Написано минимум 3 integration теста для всего приложения
- [ ] Все тесты проходят успешно (`npm test`)
- [ ] Использованы `data-testid` для упрощения тестирования
- [ ] Код покрыт тестами не менее чем на 70%
- [ ] В проекте есть `README.md` с инструкцией по запуску тестов

## 📤 Как сдать

Упакуй проект в ZIP (без `node_modules`) и отправь файл.
