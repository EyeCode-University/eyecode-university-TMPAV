# Задание: Тестировщик королевской казны

> **Task ID:** `jest-01`

## Суть задания

Ты напишешь **unit-тесты для калькулятора** с помощью Jest. Сам калькулятор ты создашь через AI — это разрешено и даже обязательно. А вот тесты — только своими руками и своей головой.

Задание учит главному навыку тестировщика: **думать как калькулятор сломается**, а не как он работает.

---

## 📋 Пошаговый план

### 1️⃣ Создай проект

Инициализируй Node.js проект через `npm init -y`. Установи Jest:

```
npm install --save-dev jest
```

В `package.json` добавь в секцию `scripts`:
```json
"test": "jest"
```

---

### 2️⃣ Сгенерируй калькулятор через AI

Открой любой AI-ассистент и попроси его написать файл `calculator.js` с четырьмя функциями:

| Функция | Что делает |
|---------|------------|
| `add(a, b)` | Сложение |
| `subtract(a, b)` | Вычитание |
| `multiply(a, b)` | Умножение |
| `divide(a, b)` | Деление |

Каждая функция должна быть экспортирована через `module.exports`. Прочитай сгенерированный код и **пойми каждую строку** — тесты будешь писать ты, а не AI.

---

### 3️⃣ Создай файл тестов

Создай файл `calculator.test.js`. Импортируй функции из `calculator.js`.

Структура каждого теста:
```js
test('описание что проверяем', () => {
  expect(результат).toBe(ожидаемое_значение);
});
```

Группируй тесты по функциям через `describe`:
```js
describe('add', () => {
  // все тесты для сложения
});
```

---

### 4️⃣ Напиши тесты для обычных случаев

Для каждой из четырёх функций напиши минимум **2 обычных теста**:
- Два положительных числа
- Положительное и отрицательное число

Это разминка. Настоящая работа — дальше.

---

### 5️⃣ Напиши тесты для граничных случаев

Вот где начинается настоящее тестирование. Подумай и напиши тесты для каждой ситуации:

| Ситуация | Вопрос который ты задаёшь |
|----------|--------------------------|
| Деление на ноль | Что возвращает `divide(5, 0)`? Ошибку или `Infinity`? |
| Ноль как аргумент | `multiply(0, 999)` — всегда ноль? |
| Отрицательные числа | `subtract(-3, -7)` — правильный знак? |
| Дробные числа | `add(0.1, 0.2)` — равно ли `0.3`? (спойлер: нет) |
| Очень большие числа | Работает ли `multiply(999999, 999999)`? |
| Строки вместо чисел | Что случится если передать `add('5', 3)`? |

> 💡 Для дробных чисел используй `toBeCloseTo` вместо `toBe` — иначе тест упадёт из-за особенностей JavaScript с числами с плавающей точкой.

---

### 6️⃣ Запусти тесты и разбери результат

Запусти `npm test`. Jest покажет какие тесты прошли, а какие упали.

Если тест упал — это не ошибка в твоих тестах. Возможно, **AI написал калькулятор с багом**. Исправь калькулятор вручную и запусти снова.

Добейся чтобы все тесты были зелёными.

---

### 7️⃣ Напиши отчёт в README

В `README.md` опиши:
- Сколько тестов написал и сколько прошло
- Какие баги нашёл в AI-калькуляторе (если нашёл)
- Что тебя удивило при тестировании дробных чисел
